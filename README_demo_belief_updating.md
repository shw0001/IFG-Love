# VBA toolbox  demo_belief_updating

VBA toolbox does not require installation and can be run directly on matlab.


Open matlab (e.g.,matlab R2019a)


Model estimation:
Step1. cd D:\VBA_Code\VBA_toolbox_master;
Step2. Enter 'demo_belief_updating()' into the matlab Command  Window and Run it;
Step3. The running Results will be found in D:\VBA_Code\VBA_toolbox_master\Results.

Model comparisons:
Step1. cd D:\VBA_Code\VBA_toolbox_master;
Step2. Enter 'modelComparison_shw001 ()' into the matlab Command  Window and Run it;
Step3. The running Results will be found in the matlab Command Window.

Parameter recovery:
Step1. cd D:\VBA_Code\VBA_toolbox_master;
Step2. Run Parameter_recovery.m;
Step3. The running Results will be found in D:\VBA_Code\VBA_toolbox_master\Results.
